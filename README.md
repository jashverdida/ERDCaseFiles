# Sir Eijay's ERD Case Files

A self-contained, responsive ERD practice game. The entire app is served from
`index.html`; it has no build step or npm dependencies.

## Run locally

Open `index.html` in a browser.

## Deploy to Vercel

1. Import the GitHub repository into Vercel.
2. Set the project root to the repository root.
3. Choose **Other** as the framework preset.
4. Leave the build command and output directory unset.
5. Deploy. Vercel will serve the root `index.html`.
